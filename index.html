개인 프로젝트

GitHub Repository →

기간 : 2025.12.27 ~ 2026.01.21
Java 11 · Spring Boot · Redis(Redisson) · JPA · QueryDSL · MySQL · Docker

멀티 서버 환경에서 대규모 동시 요청의 정확성과 무결성을 보장하는
선착순 티켓 발급 백엔드 시스템

  • DB Exclusive Lock의 핫스팟·데드락 문제를 파악하고, 동시성 제어를 Redis 분산락으로 이관

  • JUnit 기반 통합 테스트로 15스레드 × 10,000건 동시 요청 시나리오를 재현하고 중복 발급 0건 · 초과 발급 0건 검증
  • 헥사고날 아키텍처 기반으로 도메인·인프라 분리 설계

개인 프로젝트 (진행 중)

GitHub Repository →

기간 : 2026.05 ~
Spring Boot · Hexagonal Architecture · Redis · FCM · Docker · GitHub Actions

사용자가 등록한 날씨 조건(비·폭염·강풍 등)이 충족되면
FCM 푸시 알림을 자동 발송하는 백엔드 서비스

  • FCM 연동으로 도시·조건별 맞춤 푸시 알림 발송
  • Docker Compose + GitHub Actions CI/CD 파이프라인 구성
